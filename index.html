✓ RF447 호환 목록에 등록된 모델

기존 호환 목록에 등재된 모델입니다. 해당 단지에서 실제 설치를 완료했다는 의미는 아니며, 단지별 배선·사양 확인이 필요합니다.

! RF447 연동 어려움

연동이 어렵다는 현장 의견이 있으나 일부 가능한 사례도 있어, 해당 단지의 사양과 모듈을 확인해야 하는 경우입니다.

✕ RF447 연동 불가 정보 있음

공식 안내 등에서 연동 불가 정보가 있는 경우입니다. 일반 설치 기준인지 특정 단지 사양인지 결과 설명의 적용 범위를 확인해 주세요.

! 일반 설치 불가 안내 · 개별 현장 성공 사례 있음

공식 안내상 일반 설치 불가이지만 개별 현장 성공 사례가 함께 있는 경우입니다. 성공 사례를 다른 단지의 일반 설치 가능으로 확대하지 않습니다.

! RF447 호환 여부 확인 필요

정보 부족, 근거 상충 또는 단지별 차이로 확인이 필요한 경우입니다. 미확인은 연동 불가를 뜻하지 않습니다.

! 일반 사양 RF447 연동 가능 · 아파트 전용 사양 주의

일반 사양의 가능 현장 정보가 있으나 특정 아파트 전용 사양에는 불가 정보가 있어 단지별 확인이 필요한 경우입니다.

✕ 해당 아파트 전용 사양 · RF447 연동 불가
